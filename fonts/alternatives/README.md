# Başlık fontu alternatifleri

Mevcut başlık fontu Fraunces. Benzerlik değerlendirmeleri görsel tasarım önerisidir. Türkçe karakter kontrolü TTF cmap tablolarında ÇĞİÖŞÜçğıöşü harfleri için yapıldı; tüm alternatifler bu harfleri içerir.

Önizleme: http://localhost:8000/font-onizleme.html

- Young Serif: https://fonts.google.com/specimen/Young+Serif
- DM Serif Display: https://fonts.google.com/specimen/DM+Serif+Display
- Lora: https://fonts.google.com/specimen/Lora
- Newsreader: https://fonts.google.com/specimen/Newsreader
- Cormorant Garamond: https://fonts.google.com/specimen/Cormorant+Garamond

Dosyalar Google Fonts resmî deposundan indirildi: https://github.com/google/fonts/tree/main/ofl
Her aile klasöründe OFL.txt ve orijinal METADATA.pb dosyası bulunur.
